## 建议顺序

```
09（对简历逐条背口径）→ 07（把项目讲明白）→ 02（练追问）→ 04（LB/SQL 专题）
        → 01（补通用底子）→ 05（默写命令）→ 06（考前冲刺）
```

**一条原则**：每道题都要能挂上「我在自己机器上跑过，当时看到 XXX」。
只有 L1（说出命令）是及格，L3（说出真实现象和排查过程）才是录用线。

> 文档里的命令和输出，都能在本仓库 `project1-cluster/` `project2-lnmp/` 里找到对应配置。
