# 面试题索引

16 份文档 + 1 份打印版，三类用途：**练题**（01–04、08、09、11、13、14、16）、**速查**（05、06、10、12）和**专项**（07）。
所有答案都对着本仓库的两个项目写，能拿实际输出佐证，不背空话。

> **开场必问题**：`16-项目总述口述稿.md`（"介绍你最复杂的项目"——90 秒版 + 3 分钟版 + "几个人做的"怎么答）。
> **只想背一份**：`13-Linux基础面试总纲.md`（96 题按 S/A/B/C 重要度排序，每题 30 秒版 + 展开 + 追问）。
> **只想看项目**：`09-新简历拷打手册.md` + `14-踩坑×简历面试题.md`。
> **只想练坑**：`14-踩坑×简历面试题.md`（25 条坑对应 26 道题，带陷阱和止损话术）。

## 建议顺序

**路线 0 · 面试前一晚（只背开场）**
```
16（项目总述 90 秒版 + "几个人做的"话术）→ 13 的 S 级 26 题 → 06（考前 2 小时冲刺）
```

**路线 A · 只有一块时间（3 天速通）**
```
16（开场先把项目说清）→ 13（96 题按重要度过一遍，S 级必须全通）→ 07（把项目讲明白）→ 06（考前 2 小时冲刺）
```

**路线 B · 时间充裕（一周）**
```
16（开场）→ 09（对简历逐条背口径）→ 14（把每个坑练成问题）→ 07（把项目讲明白）→ 02（练追问）
        → 04（LB/SQL 专题）→ 13（按 S→A→B→C 补全）→ 01（回到分章细节）→ 05（默写命令）→ 06（考前冲刺）
```

**一条原则**：每道题都要能挂上「我在自己机器上跑过，当时看到 XXX」。
只有 L1（说出命令）是及格，L3（说出真实现象和排查过程）才是录用线。

> 文档里的命令和输出，都能在本仓库 `project1-cluster/` `project2-lnmp/` 里找到对应配置。
