# 12-基础保底题（简单版）

> 定位：基础差就先保基础分。这套全是「一句话答案」，背熟了起码基础环节不丢分。
> 每题答案刻意压到 1~2 句，括号里是记忆钩子。

## 一、Linux 基础（15 题）

**1. Linux 里切换目录用什么命令？**
`cd /path`。回上一级 `cd ..`，回家目录 `cd` 或 `cd ~`。

**2. 怎么看当前在哪个目录？**
`pwd`（print working directory）。

**3. 怎么看目录里有什么文件？**
`ls`。要详细信息（权限/大小/时间）用 `ls -l`，看隐藏文件 `ls -a`。

**4. 怎么看文件内容？**
小文件 `cat 文件名`；大文件用 `less`（可翻页按 q 退出）；看最后几行 `tail -f 日志`（实时盯日志就是它）。

**5. 复制、移动、删除文件？**
`cp 源 目标`、`mv 源 目标`（移动和改名都是它）、`rm 文件`。删除目录要 `rm -r`。

**6. -rwxr-xr-- 是什么意思？**
三组三个字符：**属主** rwx（读写执行）、**属组** r-x（读和执行）、**其他人** r--（只读）。数字表示：7=4+2+1=rwx，所以是 754。

**7. 怎么改文件权限和属主？**
`chmod 755 文件`（改权限）、`chown user:group 文件`（改属主属组）。

**8. 怎么查找一个文件？**
`find / -name "文件名"`。只找命令在哪用 `which 命令名`。

**9. 怎么在文件里搜内容？**
`grep "关键词" 文件`。加 `-i` 忽略大小写，`-r` 递归搜目录，`-n` 显示行号。

**10. 怎么看系统内存还剩多少？**
`free -h`。**看 available 那列**才是真实可用（free 列被缓存占着，其实随时能还）。

**11. 怎么看磁盘空间？**
`df -h`（看整个文件系统）；看某个目录占多少 `du -sh 目录`。

**12. 怎么看哪些进程最耗资源？**
`top`，Shift+M 按内存排序、Shift+P 按 CPU 排序，q 退出。

**13. 怎么杀掉一个进程？**
先 `ps aux | grep 进程名` 找到 PID，再 `kill PID`。杀不掉用 `kill -9 PID`（强杀，最后手段）。

**14. 怎么看某个端口被谁占了？**
`ss -tlnp | grep :80`。看所有监听端口就是 `ss -tlnp`。

**15. 怎么测试网络通不通 / 端口通不通？**
通不通 `ping IP`；端口通不通 `curl -v IP:端口` 或 `telnet IP 端口`；看路由路径 `traceroute IP`。

## 二、MySQL 基础（8 题）

**16. 怎么登录 MySQL？**
`mysql -uroot -p`，回车后输密码（密码不跟在 -p 后面更安全）。

**17. 增删改查四个基本语句？**
`INSERT INTO 表(字段) VALUES(值)`；`DELETE FROM 表 WHERE 条件`；`UPDATE 表 SET 字段=值 WHERE 条件`；`SELECT 字段 FROM 表 WHERE 条件`。**改和删不带 WHERE 是事故**。

**18. 怎么看有哪些库、哪些表？**
`SHOW DATABASES;` 进库 `USE 库名;` 后 `SHOW TABLES;`。

**19. 怎么看表结构？**
`DESC 表名;`（describe）。

**20. 什么是索引？为什么快？**
类似书的目录。没有索引要一页页翻（全表扫描），有索引直接翻目录定位。代价：占空间，写入时要维护目录所以变慢。

**21. 什么是主键？和外键的区别？**
主键：一行数据的唯一标识，不能重复不能为空。外键：指向另一张表的主键，用来关联两表。

**22. 什么是慢查询？怎么发现？**
执行很慢的 SQL。开慢查询日志（`long_query_time=0.5`，超过 0.5 秒记下来），然后逐条 EXPLAIN 分析。

**23. 备份数据库用什么命令？**
`mysqldump -uroot -p 库名 > 备份.sql`。恢复：`mysql -uroot -p 库名 < 备份.sql`（备份是 > 导出，恢复是 < 导入）。

## 三、LNMP 基础（7 题）

**24. LNMP 是什么？**
Linux + Nginx + MySQL/MariaDB + PHP，一套动态网站服务架构。请求流向：用户 → Nginx → PHP 处理 → MySQL 取数据 → 返回。

**25. Nginx 是干什么的？**
Web 服务器，三个常用身份：①直接提供静态文件 ②反向代理（把请求转给后端）③负载均衡（把请求分给多台后端）。

**26. 正向代理和反向代理的区别？**
正向代理代理**客户端**（翻墙工具，服务器不知道真实用户是谁）；反向代理代理**服务端**（Nginx，用户不知道后面有几台服务器）。

**27. 改完 Nginx 配置怎么生效？**
先检查语法 `nginx -t`，没问题再 `nginx -s reload`（平滑重载，不断连接）。**直接 restart 会断线上请求**。

**28. 常见 HTTP 状态码什么意思？**
200 成功；301 永久跳转；404 页面不存在；403 没权限；500 服务端代码错了；502 后端挂了；504 后端超时。

**29. 怎么看 Nginx 日志排查问题？**
两个日志：`access.log` 记每个请求（谁、什么时候、访问什么、返回码）；`error.log` 记错误。502 就去 error.log 看后端为什么连不上。

**30. Docker 里怎么进一个运行中的容器？**
`docker exec -it 容器名 bash`（或 sh，Alpine 镜像是 sh）。

## 四、Redis 基础（4 题）

**31. Redis 是什么？为什么快？**
内存里的 key-value 数据库。快是因为：数据在内存（内存比磁盘快万倍）+ 单线程没锁竞争。

**32. 什么场景用 Redis？**
缓存（把数据库的查询结果存起来，下次直接拿）+ 共享 session（多台机器共用登录状态）。

**33. 缓存和数据库的数据不一致怎么办？**
给缓存设过期时间（TTL），过期后重新从数据库读。我项目里设的 60 秒，最多接受 60 秒的旧数据。

**34. Redis 挂了会怎样？**
如果只是当缓存：数据库顶上来，变慢但不停服。所以我做了降级——Redis 连不上就直接查 MySQL，缓存不是必需品。

## 五、Zabbix 基础（4 题）

**35. Zabbix 是干什么的？**
开源监控平台：定期采集服务器的 CPU/内存/磁盘等指标，超过阈值就告警（发钉钉/邮件）。

**36. Zabbix 的几个核心概念？**
主机（被监控的机器）→ 监控项（采什么指标，如 CPU 使用率）→ 触发器（什么情况算异常，如 CPU>90% 持续 5 分钟）→ 动作（异常了干什么，发告警）。

**37. Zabbix 怎么采集数据？**
两种：Agent（被监控机器上装 agent 主动上报，最常用）和 SNMP/自定义脚本（网络设备或特殊指标）。

**38. 收到磁盘告警后的处理流程？**
`df -h` 确认使用率 → `du -sh /*` 一层层找大目录 → 通常是日志 → 清理/轮转 → 处理完确认告警自动恢复（**告警有恢复通知才说明监控闭环了**）。
